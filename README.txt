# FVR Visuals Website

## How to use
1. Upload `index.html` and `style.css` to your GitHub repository.
2. Create/use the `assets` folder.
3. Put your images there using these names:
   - thumbnail-1.png
   - thumbnail-2.png
   - thumbnail-3.png
   - thumbnail-4.png
   - pfp-1.png
   - pfp-2.png
   - pfp-3.png
   - pfp-4.png
4. Your Formspree endpoint is already included in the contact form.
5. Commit the changes and open your GitHub Pages site.

You can replace the image files with your own work while keeping the filenames.
