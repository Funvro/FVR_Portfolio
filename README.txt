# FVR Visuals Portfolio

Open `index.html` in a browser to preview the site.

Before publishing:
1. Replace the Instagram link in `index.html`.
2. Replace the Discord placeholder link in `index.html`.
3. Add PFP/poster/logo images to `assets/` and add cards in the Showcase section.
4. Replace any experience text with your exact real experience.
5. The testimonial text is a polished paraphrase of client feedback, not a verbatim quote.

The hero background is a CSS recreation of the dark video-editor/timeline aesthetic from the reference, so it does not copy the reference site's artwork.
